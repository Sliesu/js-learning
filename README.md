# JavaScript 系统学习项目（从零基础到语言全貌与数据处理）

本项目是一套以 **JavaScript 脚本能力、数据调用与数据处理** 为核心的系统化训练工程。你不需要操心页面和样式，只要专注于 JavaScript 语言本身与数据处理能力。

## 快速开始

1. 启动本地静态服务（浏览器 ES Module 与 `fetch` 需要通过 HTTP 访问）：

```bash
npm start
```

浏览器打开终端输出的地址：`http://localhost:3000`。它只依赖本机已安装的 Node，无需额外安装任何全局依赖或工具。

2. 也可以在终端一键运行全课示例与题解自动化校验：

```bash
npm run verify
```

## 每一课怎么练

每一课位于 `lessons/<阶段>/<课名>/` 下，包含三个文件：

- `lesson.js`：本课核心概念、必须记住的规则，以及可直接在页面右侧运行并查看输出的 `runDemo(ctx)` 示例。
- `exercise.js`：留给你的动手练习函数（初始状态未实现，直接测试会失败）。
- `solution.js`：标准参考实现，以及自动批改测试套件 `test(mod, assert, ctx)`。

**标准学习闭环：**
1. 打开页面，从左侧选一课。左边是讲解和例子输出，右边是可以改的代码。
2. 直接在右边写下这题，点「检查这题」（或按 ⌘↵ / Ctrl+Enter）。
3. 全部通过后，左侧这课会标成「过了」。你的答案会保存在浏览器里；如果通过项目自带的服务运行，写过的题目也会在服务器上保留，刷新后依然保留。
4. 卡住再点「看题解」。想重做就点「恢复原题」。

## 本地数据集 (`data/`)

所有数据处理课与综合实战共享四份结构化 JSON 数据：
- `data/users.json`：用户档案（城市、会员等级、活跃状态、注册日期）
- `data/products.json`：商品目录（品类、单价、库存）
- `data/orders.json`：订单及嵌套订单明细（状态、下单时间、商品项）
- `data/logs.json`：服务调用日志（级别、服务名、耗时、键值对消息）

## 课程地图（17 个阶段 · 80 课）

- **阶段 0：怎么使用本项目**（`0.1` – `0.2`）
- **阶段 1：值、类型与运算**（`1.1` – `1.8`：严格模式、7 种原始类型、IEEE-754 与金额精度、Unicode、短路求值、`===` 与 `Object.is`、显隐式转换、`BigInt`）
- **阶段 2：控制流与作用域**（`2.1` – `2.5`：分支、5 种循环、`break`/`continue`、`let`/`const` 与暂时性死区 TDZ、块级作用域闭包绑定）
- **阶段 3：函数**（`3.1` – `3.7`：声明与表达式、默认/剩余参数、箭头函数与 `this`、纯函数、闭包私有状态、高阶函数、树形递归）
- **阶段 4：用对象和数组处理数据**（`4.1` – `4.8`：`Object.hasOwn`、计算属性、解构与展开、稀疏数组、`map`/`filter`/`flatMap`/`reduce`、`toSorted`/`with`、`structuredClone`、`JSON` 读写本地数据）
- **阶段 5：标准内置对象**（`5.1` – `5.7`：字符串方法、`Intl.NumberFormat`、`Date` 与 `Temporal` 探测、正则命名捕获组、`Map`/`Set` 集合运算、`WeakMap`/`WeakRef`、`Object.groupBy`）
- **阶段 6：原型与类**（`6.1` – `6.6`：原型链、手写 `new`、`class`、`extends`/`super`/`static`、`#private` 私有字段与品牌检查、`Object.create(null)`）
- **阶段 7：错误与脏数据**（`7.1` – `7.4`：`try/catch/finally`、自定义 `Error` 与 `cause`、`?.` 与 `??`、真实脏数据清洗管道）
- **阶段 8：模块**（`8.1` – `8.3`：具名导出导入、默认导出与重导出、动态 `import()` 与顶层 `await`）
- **阶段 9：异步——调用数据**（`9.1` – `9.8`：事件循环与微任务、防抖定时器、`Promise` 链、`async/await`、`allSettled` 组合器、`fetch` 本地数据、`AbortController` 超时控制、并发多表合并）
- **阶段 10：迭代器、生成器与 Symbol**（`10.1` – `10.4`：`Symbol`、可迭代协议、`function*` 惰性分块、`for await...of` 异步分页流）
- **阶段 11：元编程**（`11.1` – `11.4`：`get`/`set`、属性描述符与 `deepFreeze`、`Reflect`、`Proxy` 变更审计）
- **阶段 12：文本与二进制数据**（`12.1` – `12.3`：`TextEncoder`/`TextDecoder`、`ArrayBuffer`/`DataView` 二进制协议头、`Blob` 异步读写）
- **阶段 13：浏览器中的数据出入口**（`13.1` – `13.5`：`URLSearchParams`、`localStorage` 封装、`IndexedDB`、`Web Worker`、`ReadableStream`）
- **阶段 14：执行数据**（`14.1` – `14.4`：过滤/多键排序/分页/投影、分组聚合、`Map` 哈希关联 Join、`pipe`/`pipeAsync` 函数管道）
- **阶段 15：补齐与自测**（`15.1` – `15.4`：`tap` 结构化调试快照、编写单元测试、`performance.now` 基准对比、现代语言特性全扫描）
- **阶段 16：综合练习**（`16.1` – `16.2`：三表关联经营报表、远程接口 + 本地降级容错管道）
